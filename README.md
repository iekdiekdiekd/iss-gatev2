# ISSPanel - کامل‌ترین پنل مدیریت پروکسی

## 🚀 دیپلوی یک‌کلیک روی Railway

1. ریپازیتوری رو به GitHub آپلود کنید
2. در Railway → New Project → Deploy from GitHub
3. ریپازیتوری رو انتخاب کنید
4. همه چیز اتوماتیک انجام میشه!

## 📦 پروتکل‌های پشتیبانی‌شده

- **VLESS + WebSocket** (با پشتیبانی TLS/Reality)
- **VLESS + XHTTP** (با پشتیبانی TLS/Reality)
- **VLESS + gRPC** (با پشتیبانی TLS/Reality)
- **MTProto** (پروکسی تلگرام)
- **WireGuard** (VPN مدرن)

## 🔧 تنظیمات پیشرفته VLESS

| تنظیم | گزینه‌ها |
|-------|----------|
| شبکه | WebSocket, XHTTP, gRPC, TCP |
| امنیت | None, TLS, Reality |
| Flow | xtls-rprx-vision, xtls-rprx-vision-udp443, ... |
| Fingerprint | Chrome, Firefox, Safari, Edge, Random |

## 🔑 دسترسی

- **پنل مدیریت**: `/admin`
- **داشبورد کاربر**: `/dashboard`
- **ورود**: `admin` / `admin123` (تغییر دهید)
